JS日历系统移植到Vue

Posted at 2026-11-08
#Study #Vue3

前言

Vue3学完也有快一周了，第一次尝试把JavaScript的东西移植到Vue上，感受到了两者的差异以及它们不同的思维模式，这次移植的是一个日历系统，经常出现在一些复古个人Blog上，挺有意思的，这次来讲一下如何把它转化为Vue版本，以及过程中遇到的一些坑和细节。

数据分工

首先要搭建好最基本的框架，使用table来制作，框架是thead显示Sun ~ Sat 共7天的周数，而tbody则只有一个tr和里面一个td，剩下的所有都交给Vue来完成，我们只需要在tr和td去上用v-for遍历就行，而我们一个tr里面要有7个的td（7个数据），这是因为刚好和7个星期对上

，但是当月第一天可能是星期一及以上的日期，前面的星期就会变成空的（图片上是因为当月第一天是周日所以没有空格子），所以一个td里面不仅有数字还可能有’空格’，这些都要计算好，且这个日历每天是会变化的，所以要动态的去计算，要用到computed。框架搭建好之后再创建一个hooks来专门存放日历的逻辑数据，然后我们就可以先从useCalendar.ts开始讲，这也是最重要的部分

useCalendar.ts

import {ref,computed} from 'vue'
export default function() {
  	//第一步：创建「系统日期」和「ref响应式年/月」
  	const now = new Date()
    const year = ref(now.getFullYear())
    const month = ref(now.getMonth())
    
    
    //第二步：使用计算函数来收集 包括空格 和 所以天数 装进一个数组里
    let dayArr = computed(()=>{
      //第三步：获取 「当月第一天是星期几？」和「当月的总天数」
      let firstDayOfWeek = new Date(year.value, month.value, 1).getDay()
      let totalDay = new Date(year.value, month.value + 1, 0).getDate()
     	//---!获取后就可以通过当月第一天的数字来判断前面有多少个空格了（firstDayOfWeek返回0 ～ 6）（totalDay返回当月一共有多少天 !---
      
      //定义一个空数组来存放所有数据
      let List = []
      //然后用for循环来分别找出 空格子 和 当月所有数字
      for(let i=0;i < firstDayOfWeek; i++) {
        List.push('')
      }
      for(let j=0;j <= totalDay; j++) {
				List.push(j)
      }
      //最后把装满数据的List给dayArr
      return List
    })
    
    
    //第四步：再使用计算函数来把刚才的dayArr进行分割
    //我们不需要管里面有什么，只需要知道把dayArr的数据每次分出7个装到一个小数组里，再用一个大数组把分割好的数据装进去，就得到我们的格式了
    let rowSeven = computed(()=>{
      let newList = []
    //！！！因为dayArr是数组，而computed是ref要加value，数组不能直接跟数字比要加length，用长度比
    for (let i = 0; i < dayArr.value.length; i += 7) { //！！！记得i+=7，不然i不会保存
        newList.push(dayArr.value.slice(i, i + 7)) //！！！第二个i+7不会影响i
     }
  	 //最后把整理好的数据给rowSeven
   	 return newList
    })
    
    
   	//!---到这步日历系统基本上已经制作好了，只需要把数据return出去对方并接收就可以使用了，但这里我还要做一个东西，就是「高亮显示当天」但需要App.vue的参与，你可以直接看下面的框架先把上面搞清楚，再接着看「高亮显示当天」---!
    
    
    function today(val: number | string) {
    //年月必须是系统年月，不然会在下一年/月也显示高亮。日必须是当天 val就是每个td，循环时对比哪个td和系统日期一致，三者都满足则高亮显示
    return val === now.getDate() && year.value === now.getFullYear() && month.value === now.getMonth()
    }
	
  
  	//记得把要用的数据给App.vue
    return { rowSeven, year, month, now, today }
    
}

关于tr和td的运作

一开始我也没搞懂它是怎么运作的，后来把它想像成双重for循环就很好理解，我们拆开来看一下，它是如何运作的

<tr v-for="(seven, index) in rowSeven" :key="index">

<td v-for="(one_day, index) in seven" :key="index" :class="{today_class:today(one_day)}">{{ one_day }}</td>
  
</tr>

首先是外层的tr，里面有一个for循环，它是以大数组为source来遍历渲染的，（看图片）这里有5个tr，代表大数组里有5个小数组，tr每次遍历都会生成一个tr，然后重点：它会去找tr双标签内有什么。发现里面有一个td，这个td又有一个for循环，它便会去执行它，这个td的source是以每一个小数组来遍历的，那再细分就是小数组的每个数据one_day，也就是一个小数组有7个数据，它就会遍历7次，就会有7个td，到这里还没有完，td双标签内还有「one_day」它就是每个数据，可以理解为一开始生成的都是框架，因为有数据只会生成框架，不写上数据它只会生成有多少个框架，数据还没有，这个「one_day」就代表把每个数据都放进对应的td里面，就呈现出图片的样式了

关于「高亮显示当天」的小细节

function today(val: number | string) {
   //年月必须是系统年月，不然会在下一年/月也显示高亮。日必须是当天 val就是每个td，循环时对比哪个td和系统日期一致，三者都满足则高亮显示
   return val === now.getDate() && year.value === now.getFullYear() && month.value === now.getMonth()
   }

这里要注意的是val它就是「这一格里的内容」（数字或空字符串），td即可能是「数字」，也可能是「空格」，所以给TS两个类型（尽量不要用any），这样可以解决报错问题，还有直接return就行，不需要if。因为这串代码就是一个表达式，到:class那边会自动成true或false

坑点：for循环i的累加

起因是我当时刚把第二个computed写完，发现Vite页面一直再加载，我当时就感觉不对劲，关闭后就一直在查看，然后发现一个问题所在，看一下当时的代码

for (let i = 0; i < dayArr.value.length; i = 7) { 
    newList.push(dayArr.value.slice(i, i + 7)) 
}

看起来没什么问题一样，但问题就在 i = 7以前大部分人都是用的i++但这次是直接加7，我也是第一次用这种方式，问题在于i等于7了但是下一次它还是7，永远都不会改变，因为这里其实是一个「每轮循环结束后执行的语句」（用大久i++真忘了）想要保存，就必须i += 7这样 i 就不会一直等于7，这里还要说一下里面的slice的 i+7 不会影响 i 的数据，只是让它每次截取7个数据而已，当数据不够7个时，就会把剩下的数据打包，不需要担心它会因为不满7个而报错

ps: i =7 和 i + 7 都是错误的，不同在第一个永远等于7，第二个加了没保存
