Vue3和Vue2的特征和区别

Posted at 2026-09-12
#Study #Vue

这次主要讲一下Vue2和Vue3，当然我并没有学过Vue2，主要是来和3对比一下它们之间的区别，有哪些不一样，以及一些知识点，然后顺便讲一下Vue的文件结构

关于Vue的文件

当我们把Vue下载下来后，会发现有诸多文件，当然我们不必担心要记太多，因为实际我们用到的只有一个文件夹

我们重点看src这个文件夹内，里面就是我们后继写的所有组件和入口，有main.ts和App.vue，可以理解为main.ts就是启动器，它不负责写东西，只做初始化配置。App.vue就是所有组件的根，也就是后继所有的组件都要在这里组装起来，简单说的话main.ts负责把应用启动，而App.vue负责应用长什么样，两者缺一不可，在后继写组件我们会单独创建一个文件夹在src里面，叫components里面专门存放页面中的各种模块

Vue2（选择/属性式API）

这里讲Vue2是很有必要的，因为我们需要要了解它，在后继遇到Vue2的代码时，也能看懂，先说一下Vue的框架

<template>
		//这里是写HTML
</template>
  
<script lang = ts>
  	//这里为什么要加 lang = ts 是因为Vue推荐用TypeScript写代码，当然也可以写JS代码
  	//这里是写JavaScript和TypeScript
</script>
  
<style>
  	//这里是写CSS
</style>

上面的代码就是project.vue中的代码格式，在所有的.vue文件里都是这样写的，当然你可以不要其中一些东西，只要你不使用即可，下面讲一下Vue2中的代码

<template>
		<p>{{ a }}</p> //{{}}是Vue中的文本插值语法，可以写定义的变量，还可以写一些简单的表达式
		<button @click="changeA">点击修改a</button> //@click是Vue的事件绑定语法糖 和JS中的click事件是一样的
</template>
  
<script lang = ts>
  export default { //Vue2中单文件组件实现模块化复用的核心基础，它是ES6中模块系统的默认导出机制
  	name:'Person'‌  //这个是该模块项目的名称，可以和文件名一样，也可以修改
    
  	data() { //数据：专门来定义响应式数据，页面中所有要用的变量都写在这里
       return {
         	a:10 //这里是键和值
       }
    }
  	
  
  	methods: { //方法：专门来定义函数的，所有的方法和业务逻辑都写在这里
      	changeA() { //methods中不带function关键字
          	this.a = 20 //在Vue2中的this是访问组件能力的核心，它指向的是当前组件的实例化对象
          	//可以说在Vue2中你想要调用都需要使用this
        }
    }
 }
</script>
  
<style>
  	
</style>

上面大概讲了一下Vue2的代码格式，以及它的一些用法，因为后继不到万不得已的时候，我们最好只写Vue3，千万不要两者混写，上面主要是大概了解一下2代的特征，后面讲到3代就有很明显的区别

Vue3（组合式API）

来到正题，Vue3和Vue2最大的区别就是采用了Composition API，核心在于不用像Vue2中，我要设定一个数据，然后我还要在methods中设定它的方法，以及其它的computed或watch，这样算下来要写4遍，如果有多个数据那就重复上面的操作，这样会导致冗余很大，在Vue3中我们所有的代码都只在setup() {}里面写，核心优势是在它不像Vue2要写data和methods，只需要一个setup即可，而且它弱化了this，使得所有数据和方法更方便调用

<template>
			<p>我是{{a}}</p>
      <p>我是{{b}}</p>
      <p>我是{{c}}</p>
			<button @click="getA">A</button>
      <button @click="getB">B</button>
      <button @click="getC">C</button>
</template>


<script lang = ts>
export default {
	setup() { //setup是一个函数
    // console.log(this); //setup中的this是undefined，Vue3中弱化了this
  	//数据：这里数据现在都不是响应式的
  	let a = 10;
  	let b = 20;
  	let c = 30;
  
  	//方法：现在还没用到ref/reactive所有这里的方法是不能修改页面数据的，它不是响应式的
  	function getA() { 
      	a += 1
    }
  	function getB() {
      	b -= 1
    }
  	function getC() {
      	c = a + b
    }
  	
  	//这里要将需要使用的数据导出,才能使用
    //这里的one:a,two:b是key，可以改成任意名称，那我们把它直接改成a:a,b:b
    //那就会直接触发简写行式，直接写a,b
    return {a,b,c}
}
}
</script>


<style>
</style>

可以看到这里setup还是有一个问题的，那就是每当我们创建了新数据或是方法，那我们就需要在return写一下，这也是最麻烦的点，或许有没有更方便的方法呢？答案是有的，我们只需要在script中添加setup就变成setup语法糖，它的好处是帮我们省去了写setup(){}，最重要的是它自带了return，不需要我们手动去写返回值，下面简单看一下代码

<template>
			<p>我是{{a}}</p>
      <p>我是{{b}}</p>
      <p>我是{{c}}</p>
			<button @click="getA">A</button>
      <button @click="getB">B</button>
      <button @click="getC">C</button>
</template>


<script setup lang = ts>
  	//数据
  	let a = 10;
  	let b = 20;
  	let c = 30;
  
  	//方法
  	function getA() {
      	a += 1
    }
  	function getB() {
      	b -= 1
    }
  	function getC() {
      	c = a + b
    }
</script>
