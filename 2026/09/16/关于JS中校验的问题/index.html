关于JS中校验的问题

Posted at 2026-09-16
#JavaScript #Study

这次讲上次遇到了一个问题，是一个很简单的作业，起初还以为没什么难的，结果做的时候才知道第一次做校验的坑，这次的Blog不是很长，就是主要讲一下逻辑

//题目：让用户输入三门成绩，并把这些成绩打印到页面上。要求：用户输入的必须是数字，如果不是数字就提示错误，以及空格等基本问题
//1.这道题主要考校验，重点是阻止用户输入非数字，这也是我卡住的地方，如果一个一个用if去判断，会有许多问题，这里要用到函数
//2.我们知道JS解析中，优先处理var 和 函数 三门成绩我们可以有三个调用者，每个发送的科目都不一样，让函数来进行相应的判断，最后就会把返回的值给调用的那个变量，这个变量的值就是我们要的成绩

//提前把分数变量弄好
let score;

//定义一个校验函数来处理数字的合法性
function CountScore(suject) {
  //while循环，因为用户可能会输入错误，需要重复输入
  while(true) {
  //让用户输入科目成绩
  let str = prompt(suject)
  
  //判断str是不是空的或是空格，如果是就提示并continue
  if(str === null || str.trim() === '') {
    alert('请输入成绩');
    continue;
  } 
    
  //将str转换为数字类型 (这里也可以用Number)
  let num = parseFloat(str)
   
   //如果num不是数字就会执行 提示并continue
  if(isNaN(num)) {
    	alert('请输入数字')
    	continue
	} 
  //如果上面的检测都通过了就把num给score
  score = num
	//注意！当本次检测通过后一定要break退出本次循环！！
   break;
}
  //把score返回给调用变量 (retune是函数的，不是while的，所以在外部使用)
  return score;
  
}
let c = CountScore('C语言成绩为')
let java = CountScore('Java语言成绩为')
let html = CountScore('HTML成绩为')
document.write(c)
document.write(java)
document.write(html)

最主要就是要记住while循环，用户输入错误后可以重新输入，然后就是不要忘记break，因为不退出的话，就会永远在第一个调用，当检测都通过时在最后直接退出本次循环，会自动进行下一个调用者，然后就是判断用户的输入是否合法正确，isNaN意思是如果不是一个数字就为true，是数字就为false，trim()就是将变量的左右的空格清空
