轮播图案例讲解+疑点
2026-07-31 | JavaScript Study

1.为什么移动是ul而不是图片本身呢？

这是因为如果移动图片本身的话，我们要考虑很多点，首先就是第一张图片往左移动了，那第二张呢？那就还需要给第二张加移动，还有第三张呢？所以说给图片本身是不现实的，我们只需要给到ul因为所有图片都在ul里面，而且用了float它们都在一排，当ul往 -x 方向走的时候，后面的图片就一起过来了，只要移动的图片它的大小和box一样大，就实现了ul往左走，下一个图片就跑到了上一个图片的位置，这就是为什么，给ul而不是给它的子元素li or img

3.小圆圈怎样精准与图片匹配呢？当我按下第二个小圆圈，图片就会到第二张去

小圆圈与图片匹配要先用排他思想解决点击问题，然后我们给每个出生的ol的li也就是小圆圈，添加一个「自定义属性」这样每个小圆圈都有一个编号了，有了之后，我们要计算ul移动的距离，也就是我们点哪一个圆圈，它就跳转到对应的图片，这里要用到一个算法，就是当前圆圈的索引号 * focus的宽度(可以理解为图片的宽度)，结果就是我们想要的位置
原理是：第0个索引号乘上720px = 0 第1个索引号乘上720px = 720px 那么位置为0px就是我们默认的那张图片，位置是720px的就是第二张图片的位置，1440px就是第三张图片的位置，依次类推

这里记得要添加负号，因为ul是往左走的，图上是从右边过来。这样我们点击4个圆圈的任意一个，都可以跳转至对应的图片，主要是记住那个算法，多试几遍就很好理解的

6.左右箭头的区别

在这里左右箭头的区别其实不大，它们主要是数组相反，右箭头要判断图片是否到了假图，然后进行判断，而左箭头要判断图片是否超过了第一张(默认)，进行相应的判断，总的来说它们的主要区别就是相反和判断图片位置的不同

7.左右箭头和小圆圈的关系怎么处理？

它们的主要逻辑是，当我们点击左或者右箭头时，给箭头 和 圆圈 分别添加num和circle的变量，值都为0，原理是当我们点击一下箭头

(一)如果num和index没有绑定，我们点击小圆圈移动完图片，再点击箭头移动时，图片就不会正常到下一张，因为在箭头那里看来，我还在第一张图片，但是我们已经通过小圆圈到第三张图片，这就是为什么我们要把箭头和小圆圈进行绑定

(二)如果circle和num没有绑定，当我们点击箭头移动时，下面的小圆圈还是在第一个上面，但图片已经到下一张了，我们让circle的值和num一样，然后使用排他思想，先清除所有的小圆圈的current，然后给我们circle值的那一个单独添加current，「这个circle的值和num是一样的」

这个案例的大概流程是怎样

(1)先设计好html和css部分

html = 盒子 + 图片 + 左右箭头 + 下方小圆圈

css = 盒子与图片大小一致，箭头和圆圈加浮动，图片有多个所以用ul包起来，给ul添加好浮动让图片都在一行(如果后面的图片在下面，给ul加宽度即可)

(2)鼠标进入时显示箭头

给focus(盒子)添加click，鼠标进入时显示，移出时隐藏

(3)设置小圆圈的数量（动态）

有多少个图片，就设定多少个小圆圈，使用for循环生成小圆圈，生成出来的数量与图片相同

(4)点击小圆圈显示对应的图片

创建小圆圈时添加「自定义属性」，圆圈是4个，图片也是4个，当点击第1个圆圈时不动，点击第二个时ul往左移动(-x)，第三个继续往左。得出公式

第1个小圆圈(索引号为0) * 盒子的大小(700px) = 0 意思就是点击第1个圆圈，移动0px

第2个小圆圈(索引号为1) * 盒子的大小(700px) = 700 点击第二个小圆圈时，移动700px的距离，刚才是整个图片的大小

这里需要注意，点击小圆圈时，要用到排他思想，不然每点一个圆圈就会显示一个，只能显示一个

由上得出圆圈和图片的移动公式

(5)右箭头与图片移动的设定

实现：点击右箭头 -> 图片往左走 -> 小圆圈跟着变化

声明一个变量num计算用户点击箭头的次数，每点击一次就++，默认为0。点击一下，值变成1

1 * 盒子的大小(700px) = 700px 这样就实现了箭头点击，图片移动的公式

(6)无缝切换

clone一张第1个图片在ul的最后，然后进行判断，当num到达最后一个假第1时，把ul的位置清除并把num也清除，这样ul回到了真第1张图，num计数器归零

(7)箭头与圆圈之间绑定

目前箭头点击后，图片虽然到达了下一张，但是圆圈还在原地，这是因为圆圈和箭头并没有进行同步和绑定

在设定一个变量 circle 来控制圆圈的同步，用户每点击一次箭头，num++后circle也要自增

circle自增之后，添加排他，清除所有圆圈的current，只设定：圆圈[circle].className = 'current’这样箭头点击时，圆圈也会跟着移动
(8)num、circle、index之间的关联

num = 箭头的控制变量

circle = 圆圈变量（与箭头变量相关）

index = 圆圈的索引号名称

需要把上面三个一起联合一起，也就是上面其中一个移动了，剩下两个都会受到影响

在「获取当前点击小圆圈的自定义属性的值」那里添加 num = index、circle = num因为num和circle是全局变量，不受位置的影响

(！)num的值受index影响，在前面用户点击小圆圈时，会获取当前小圆圈的值，把这个值给num，用户点击到达对应图片后，num的值也会跟着变化，就不会出现，箭头和回头各自点各自的情况了

(！)circle的值受num影响是因为，它和num是相连的原理，它只是在num++时，图片到达下一个，它就是让下面的小圆圈也跟着显示下一个，因为在上面「点击小圆圈显示对应的图片」用到了「排他思想」点击任意一个圆圈时，它都会清除所有的current，保留点击的current，这里也一样，每次num移动时，circle也会进行「排他思想」，只显示和circle的值对应的那一个小圆圈，两者不会出问题，点击圆圈那里有排他，点击箭头那里也有排他，两者使用时，都会把另一个「圆圈的current」值给清除掉

有什么可以优化的地方？

目前可以优化的地方就是把左右箭头都相同的「清除current」代码封装成一个函数，让它们调用即可，这样可以节省代码空间，整体更好看
