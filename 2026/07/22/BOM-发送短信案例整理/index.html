发送短信案例整理

Posted at 2026-07-22
#JavaScript #Study

讲一下昨天的一个小案例，就是发送短信验证码的一个小案例，我95%都是我自己做出来的，接下来我来说一下
剩下5%的问题所在

1.多出来的setTimeout

昨天的代码其实只用setInterval就可以直接做出来，但是我在写的时候觉得要弄一个时间倒计时才可以
所有多写了一个setTimeout导致步骤多余了，这里面写的也只是一个btn.disable = false，60000 这完全是不用的

2.忘记添加时间复原

昨天的代码到最后到解决的一个问题就是，当我点击了按钮后，时间到了但是呢，当再次点击的时候，按钮只是被禁用了一下，就立马恢复了，后面是看老师的讲解才知道的，当time=0时就把btn的文字和倒计时的时间全部再重置一下就好了

3.关于btn.disable = false最后写在了哪里

这句话我最后跟着老师写在了当time=0的那块代码区，很简单，就是当时间为0时把按钮的禁用给解除，按钮的时间也就不用单独写一个时间了，它只需要跟随time就好，当time为0时，它就顺便解除

4.为什么点击后会等一会才开始倒计时

因为我们的setInterval的回调时间是1000毫秒，也就是1秒，当点击按钮时，会等待一秒才开始，想要解决也很简单，在else最前面添加

btn.disabled = true;
btn.innerHTML = '請等待' + djs + '秒再試'; // 點擊瞬間立刻更新文字！
djs--; // 預先扣除 1 秒

上面是Gemini给我找到的一个小bug，特别感谢:）

5.完整JS代码展示

//1.获取元素
var input = document.querySelector('input');
var btn = document.querySelector('button');
var djs = 3;
var loading = null;
//2.当按钮按下
btn.addEventListener('click', function () {
    //这里是一个判断条件，如果为空或者超出号码范围，就提示用户修改
    if (input.value == '' || input.value.length < 11 || input.value.length > 11) {
        alert('请输入正确号码再试')
    } else {
        //满足条件后会先把按钮禁用，然后在setInterval里面判断
        btn.disabled = true;
        loading = setInterval(function () {
            //如果倒计时秒数为0的话，就清除这个setInterval, 然后把按钮给复原，把倒计时也复原
            if (djs == 0) {
                clearInterval(loading)
                btn.innerHTML = '获取验证码';
                btn.disabled = false;
                djs = 3;
            } else {
                //秒数还没等于0时，就一直改变btn里面「倒计时」的文字
                btn.innerHTML = '请等待' + djs + '秒再试';
                djs--
            }
        }, 1000) 
    }
})
