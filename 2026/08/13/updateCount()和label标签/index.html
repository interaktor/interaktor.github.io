核心统计函数：updateCount()

想要在TodoList里面实现「active」「completed」这两个状态的计数系统的话，一般来说有两种选择，第一个就是声明一个变量，然后在增加，删除，选择时进行加减的操作，但是这样会有一个很致命的问题，就是在增加或减少时，你必须记得它的位置和逻辑，每添加一个你就要会思考一次，一旦增减变多，事件就会变得很乱，脑子也容易宕机
所以这里有一个新方法，就是在JS中创建一个函数，名称updateCount，原理就是每次有增减等操作时List会发生改变的时候，就让这个函数执行一次，函数内是动态获取的，每次执行都会获取最新的数量

//updateCount函数讲解
function updateCount() {
	//1.先获取所有的list
	var listAll = document.querySelectorAll('li');
	//2.再获取所有带completed的list（带完成类名的list）
	var completed = document.querySelectorAll('.completed');
	//3.算出当前没完成的list数量，注意！因为它是获取过来的是一个列表（有多个）我们要让它们相减，必须是数字相减才行，所以要让这两个元素的长度相减才正确，这样才是一个具体的数字，而不是模糊的概念！
	var active = listAll.length - completed.length;
	
	//4.把值实时给 active 和 completed 
	//在这里如果你没有获取过active和completed，直接在querySelector()后面接innerHTML
	//如果你已经在函数外获取过active和completed，直接输入获取的名称接innerHTML即可
	active_conut.innerHTML = active;
	completed_conut.innerHTML = completed;
}

HTML <label> 标签的绑定机制

label这个标签在基础HTML中就学过的，它的原理是让两个元素「绑定」在一起，最常用的是让input和内容进行绑定，「当点击内容的时候，这个input也会触发，当前点击input，文字也可以进行相应的处理」，它可以让两个元素绑定之后，我们只需要处理其中一个关键的元素就可以控制另一个元素

<label>
	<input type='checkbox'>
	<p>我是内容</p>
</label>

//1.用JS来处理，当我点击了当前input后，我就让旁边这个p，把它的样式之类的进行改变
if(e.target.tagName === 'INPUT') {
	//2.把这个p先拿过来，存在一个变量里
	let current_p = e.target.nextElementSibling;
	//3.然后再判断，这里再判断我点击的这个input它的状态是什么，根据input的不同来写
	if(e.target.checked == true) {
	//4.如果当前input被选中或打开之类的，我们就让文字也跟随变化
		current_p.className = 'lis style';
	} else {
	//当前状态被取消之类的，我们就让文字回归默认状态
		current_className = 'lis';
	}
}
