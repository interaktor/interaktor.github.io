移动端拖动元素案例

Posted at 2026-08-05
#JavaScript #Study

获得手指和盒子的初始坐标

我们想要让鼠标拖动盒子，首先就要获取「手指初始的位置」和「盒子初始的位置」，这两个用全局变量给它们存储起来，因为后面有多少函数都要使用

//所有的变量都是全局的，所以我们需要在函数外声明
//因为它们都是存储的数值，我们用0先代替
var touchX = 0;
var touchY = 0;
var boxX = 0;
var boxY = 0;
//怎么获取手指初始位置
//手指初始位置可以通过触摸事件对象targetTouches获得到
//targetTouches正在触摸元素的手指个数（列表）
//加上pageX/Y，也就是获得当前点击的手指，位于页面的x和y的坐标
touchX = e.targetTouches[0].pageX
touchY = e.targetTouches[0].pageY
//因为这里是touchstart，也就是点击的一瞬间获取的位置，那就是初始位置
//获得盒子初始位置
//盒子的初始位置很简单，只需要offset即可
boxX = div.offsetLeft;
boxY = div.offsetTop;

计算手指的移动距离

这里似乎回到了模态框，也需要计算移动距离，只不过这里是手指的。当手指点击后，会获得一个手指初始值，手指拖动时会持续获得当前手指值，如此我们就获得了最重要的两个数值，「手指初始值」和「手指当前值」大减小

//手指移动距离就是「touchmove里触摸事件对象」减去「touchstart里的触摸事件对象」
//这里是touchmove会获得手指拖动时获得的坐标，它是可以持续获得的
var moveX = e.targetTouches[0].pageX - touchX;
var moveY = e.targetTouches[0].pageY - touchY;

移动盒子

上面已经获得了手指的移动距离，那我们手指移动其实就是盒子移动，我们把「手指的移动距离」赋值给盒子，这样就可以实现手指移动的时候，盒子就会跟着一起移动了

//我们已经得到手指的移动距离了，也就是手指在页面上移动位置。
手指一直移动的坐标 - 手指初始(第一次点击的位置)坐标，就可以得到我们手指在页面上时刻移动的动态坐标
这个坐标就好比鼠标一样，可以持续获得它，把这个坐标赋给盒子也好其它东西也好，它们都可以像手指一样去自由的移动

//移动盒子记得加上它原本的位置，不然它每次移动完都会回到初始位置，因为我们在全局变量时，给的都是0
也就是每次点击div它的位置都会变成0，因为touchstart每次点击都会获取它的当前位置
它的当前位置没有改变，一直都是0，所以不加原本位置的话，它每次点击都会跑到0这个坐标上去

div.style.left = boxX + moveX + 'px';
div.style.top = boxY + moveY + 'px';
