节流阀（轮播图案例）

这里主要讲一下节流阀的原理是怎么实现的，主要用到轮播图里的左/右箭头

right.addEventListener('click', function () {
            if (flag) {
                flag = false;
                //箭头判断
                if (num > ul.children.length - 2) {
                    num = 0
                    ul.style.left = 0;
                }

                num++
                console.log('箭头' + num);
                Animate(ul, - num * box.offsetWidth, function () {
                    flag = true;
                });
                circle++

                // 圆圈判断
                if (circle > ol.children.length - 1) {
                    circle = 0
                }
                console.log('圆圈' + circle);
                circleClean()

            }


        })
        //9.左箭头点击，图片移动
        left .addEventListener('click', function () {
            if (flag) {
                flag = false;
                //箭头判断
                if (num == 0) {
                    num = ul.children.length - 1
                    ul.style.left = -num * box.offsetWidth + 'px';
                }


                num--
                Animate(ul, -num * box.offsetWidth, function () {
                    flag = true;
                });
                console.log(circle);

                circle--

                // 圆圈判断
                if (circle < 0) {
                    circle = ol.children.length - 1;
                }


                circleClean()
            }

首先声明一个全局变量flag作为节流阀，然后我们在动画执行完后才能执行下一个动画，也就是在click外层直接套一个判断，判断没通过，直接不执行所有代码

(1)flag默认为true，当我们点击的时候，flag变为false，此时它没法执行左箭头或者右箭头。当动画结束后，才会执行Animate的回调函数flag这时候才会变成true，因为加了判断条件，flag为true的时候才能进入左/右箭头的代码
(2)也就是当我们进入if的一瞬间，先把flag改为false，让其他箭头没法进入代码(flag为true才能进入click里面的所有代码)，等动画执行完毕后才会执行回调函数，这个时候flag再改为true
