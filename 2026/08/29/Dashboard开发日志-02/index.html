select里面的option如何选择并调用

一般来说select里面都是option，所以我们该如何选择呢？其实想要选择并调用option很简单，它跟input有不一样的地方，我们要在option里面添加value，这个value可以和option的值是一样的，填写好value后就可以在JS中进行调用工作了

.toFixed()的作用

值.toFixed()让该值显示小数位数，这个括号里面填写数字，一般填写2，即是在值原本的基础上显示后两位4.00

DOM 作用域与索引错位

  • 问：为什么在记账系统中，用 document.querySelectorAll('li') 获取索引会导致删除错位？限制在 ul.children 范围查找解决了什么问题？
  • 答：如果使用document.querySelector那么它就会在整个文档中进行查找为li的，问题就在页面如果有多少li标签，那么它寻找的范围就会扩大到整个文档，就会把其它不属于这个范畴的li给添加进来，导致程序出现错误。当使用ul.children时，它的范围就锁定的是ul里面的一个子元素，注意的是，这个ul获取的时候不能和其它功能的ul重合，这里的ul引用是finance_ul，名称为ul，这里需要特别注意，所以这个ul是最准确能够找到当前finance的li

数据类型与 forEach 遍历对象

  • 问：在渲染 localStorage 数据时，为什么不能直接用 DOM 节点去调用 forEach？JSON.parse() 提取出的“真实数组”在这里起到了什么关键作用？
  • 答：因为forEach是专为数组准备的，直接用DOM节点使用的话，它是不会认的，除非使用All获取全部是可以使用的。JSON.parse()提出的真实数字就是把我在其它地方存储的信息数据从文字型转化成了原数据(数组)给拿了出来，在这里是为forEach提供了一个数组对象

多生命周期的类名标记（为筛选做准备）

  • 问：为了后续实现动态筛选，为什么必须在“用户点击添加”和“页面初始化渲染”两处代码里，同步给 li 动态挂载表示类型的 Class 名？
  • 答：因为我需要在这两个地方判断当前的数据流是Income还是Expenses，判断之后我需要给它们打上对应的标签(ClassName)，然后单独制作一个filter函数，在“用户点击添加”和“页面初始化渲染”两处代码后面引用这个函数，就可以实现动态筛选

数据驱动视图的同步流转

  • 问：在记账系统中，数据数组（Array）、本地存储（localStorage）与页面 DOM 三者是如何保持同步更新与重新渲染的？
  • 答：首先页面DOM是主体框架，然后就是Array主要是把DOM元素的数据给存储进去，最后在利用localStorage把封闭好的Array给解包出来进行页面渲染。页面元素里面输入内容—数据数组进行相应的存储—本地存储保存数据并渲染
