foreach()的使用方法

这个方法可以理解为「专为数组/列表而生的for循环」组成如下代码，以及普通for循环的区别和它不一样的地方

Elements.forEach(function(formal-parameter){
	1.Element：是你要循环的列表/数组，这个循环对象它必须是多个，而不能是一个
	2.function：每一轮都会创建一个独立的局部作用域(列表/数组有多个值就会有多少轮，每轮创建后到下一个会进行销毁，也就是数组中每一个小元素都有专属的局部作用域，上一个执行完后就销毁然后创建下一个，互不干扰)
	3.formal-parameter：这个是形参，里面可以填三个形参，名称随便，但是每个的功能不一样，这里主要讲第一个，它主权用来存储Elements的值，类似于for循环中的Elements[i].onclick给每个元素绑定事件，或者给每个Elements的元素修改样式等等（详细见下方代码）
})
// ❌ 舊式 for 循環的災難
for (var i = 0; i < 3; i++) {
    setTimeout(function() {
        console.log(i); // 你以為會輸出 0, 1, 2？
    }, 1000);
}
// 實際輸出：3, 3, 3！ 
// 因為它們共用了同一個空間，等 1 秒後，i 已經變成 3 了。
// ✅ 使用 forEach 的獨立空間
[0, 1, 2].forEach(function(i) {
    setTimeout(function() {
        console.log(i); 
    }, 1000);
});
// 實際輸出：0, 1, 2！
// 因為每一輪循環都有一個獨立的 function 空間，把當時的 i 牢牢鎖在了自己的房間裡！
//function()括号内形参的使用
//一般第三个很少使用
//总结：第一个类似Element[i]，第二个类似i(代表具体的值)
elements.forEach(function(element, index) {
    // 1. 用第一個形參改樣式（它代表元素）
    element.style.color = 'blue'; 
    
    // 2. 用第二個形參做算術（它代表數字 0, 1, 2...）
    console.log("當前算到第 " + index + " 個元素了"); 
});

trim()的使用方法

它的代码格式如下，主要功能就是清除文本左右的空格

Element.trim() //代表把当前元素「首尾的空格」清除了（夹在文字中间的空格会保留）
//下面是具体使用场景之一
var trims = input.value.trim(); //获取没有空格的input
//这个input的value现在不能输入空格而且还必须输入1个以上的字符
if(trims.length >= 1) {
	console.log('Hello World');
}
